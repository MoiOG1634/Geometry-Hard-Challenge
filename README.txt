Geometry Hard Challenge Android project

The project embeds your HTML game in a full-screen Android WebView, uses your icon, and launches in landscape.

Build APK via GitHub Actions: upload the contents of this ZIP to a GitHub repository (branch main), open Actions, run Build Android APK. Download the Geometry-Hard-Challenge-APK artifact from the successful run. The APK will be inside the artifact as app-debug.apk.

Build is not locally tested because Android SDK and Gradle are not installed in this environment.
